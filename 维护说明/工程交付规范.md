# 工程交付规范

## Definition of Done

每次网站更新必须同时满足：

1. 修改完成，且不顺手重构无关区域；
2. build、lint、类型和维护检查通过；
3. Navbar、Hero、Experience、AI Workflow、About、Resume 未被意外破坏；
4. 图片正常加载，缺失图片可安全降级；
5. 桌面端与手机端保持可读；
6. 正式公网版本部署成功；
7. 公网首页及样式资源可访问；
8. 不依赖用户持续保持浏览器或 Mac 前台可用；
9. 完成后明确说明本次变化和验收位置。

## 默认开发方式

采用：后台修改 → 后台检查 → 自动部署 → 公网检查 → 通知用户验收。

默认不控制鼠标、键盘和前台浏览器，不主动打开多个标签页。只有用户明确要求现场调试或必须视觉验收时才使用浏览器。

## 区域状态

- 工程部署流程：`FROZEN`，除非部署故障，不做无关改动。
- 首页视觉与内容：`WIP`，按用户逐项反馈修改。
- 真实照片、PDF 简历、联系方式：`NOT STARTED`，等待用户提供素材。

`FROZEN` 区域未经明确要求不得重构。

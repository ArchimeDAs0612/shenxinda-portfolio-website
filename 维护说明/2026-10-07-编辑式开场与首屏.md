# 2026-10-07｜编辑式开场与首屏

本轮仅深化开场与 Hero，不改变职业定位、项目事实、教育、联系方式或后续章节。

- 开场：姓名分拍揭示、照片横向揭幕、细线延展，约 1.3 秒结束，不是加载屏，不锁滚动，不要求点击进入。
- 首屏：暖纸色与炭黑文字；姓名、定位、身份、说明、项目入口分层；照片采用编辑式画框。
- 证据：滴滴、极氪、挑战杯既有信息重新排成三条入口，可直接跳到经历或教育。
- 降级：系统减少动态效果时完全跳过开场；直接打开带章节锚点的网址也跳过开场；无 JavaScript 时内容仍可阅读。
- 图片：沿用原有图片维护配置和素材，没有生成或替换个人照片。
- 工程：本地工作备份不再进入源码 lint/type 检查；保留备份，不改部署工作流。
- 自动检查新增：开场有限时长、姓名可访问性、手机无横向溢出、直达章节、无 JS 阅读，以及桌面音乐控件不遮挡首屏经历或滚动入口。

正式交付仍以原 GitHub Pages 网址为准，不以本地预览代替公网验收。视觉主观评价等待本人反馈，不自动标记 FROZEN。

# Portfolio Website project rules

- Read `维护说明/工程交付规范.md` before changing this website.
- Keep all project assets, maintenance files, and documentation inside this repository.
- Work in the background by default. Do not open or control foreground browsers unless the user explicitly requests browser testing or live UI work.
- Preserve Git history and the existing public deployment paths.
- Prefer local, low-risk changes. Do not modify `FROZEN` areas without explicit user approval.
- Never invent professional experience, project results, business metrics, internal company details, photos, contact details, or resume content.
- A website task is complete only after local verification, deployment, and public URL/resource checks succeed.
